## Overview

Bottleneck Lite adds visual color indicators directly onto Factorio assemblers, miners, and furnaces to identify bottlenecks at a glance: green for running at full capacity, yellow for partially utilized, and red for idle or starved machines. Unlike the original Bottleneck mod, Lite uses a lightweight polling approach that avoids circuit network overhead.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Factorio Bottleneck Lite** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Machine Status Colors** | Green/yellow/red overlays show running, partial, and idle machines |
| **Belt Analysis** | Belt saturation indicators identify throughput-limiting transport links |
| **Low Overhead** | Lightweight polling approach avoids circuit network performance costs |
| **Configurable Thresholds** | Adjust the utilization percentages that trigger each color state |
